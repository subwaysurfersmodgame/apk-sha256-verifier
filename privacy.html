#APK SHA-256 Verifier

Repository policy

Privacy

How does local file processing work?

APK SHA-256 Verifier reads the selected file inside the browser tab. The application code contains no file-upload request, analytics script, advertising script, cookie, local-storage write, or outbound API call. The Content Security Policy sets connect-src 'none' to block outbound connections initiated by the page.

The calculator stores no hash after the browser tab closes unless the visitor copies or saves the value.

What does GitHub Pages process?

GitHub Pages delivers the website files. GitHub controls request logs and platform-level processing associated with that hosting service. GitHub’s Privacy Statement governs that processing.
