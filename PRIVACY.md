# Privacy

## Local file processing

APK SHA-256 Verifier reads the selected file inside the browser tab. The published application code contains no file-upload request, analytics script, advertising script, cookie, local-storage write, or outbound API call. The page's Content Security Policy sets `connect-src 'none'` to block outbound connections initiated by the page.

The tool stores no calculated hash after the browser tab closes unless the visitor copies or saves the value.

## GitHub Pages hosting

GitHub Pages delivers the website files. GitHub controls request logs and platform-level processing associated with that hosting service. GitHub's Privacy Statement governs that processing.
